Quick Blueprint 1.0.0
=====================

在界面左上角添加快速蓝图按钮。点击后选择一个已解锁配方，即可快速生成一条自动化生产线蓝图；该蓝图包含机器、传送带、机械臂和供电设施，并可按“原料消耗满一条传送带”或“产物输出填满一条传送带”的目标生成。

Adds a Quick Blueprint button to the top-left interface. Select an unlocked recipe to quickly generate an automated production-line blueprint with machines, transport belts, inserters, and power poles. Generate a setup designed either to consume a full belt of input materials or to fill a full belt with output products.

Choose a recipe, then configure the factory, modules, transport belt,
inserter, power pole, output direction, and machine-count target before
generating the blueprint.

Machine-count targets are selected automatically according to the recipe:
- One machine
- Output half belt or full belt
- Highest-demand input half belt or full belt
