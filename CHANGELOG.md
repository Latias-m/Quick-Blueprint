# Changelog

## 1.1.0

### 简体中文

- 配方选择改用游戏原生选择器，支持搜索、分类浏览和最近选择记录。
- 仅允许选择已解锁且适用于生产线的配方。
- 调整配置界面布局，选择配方前也可设置传送带、机械臂、电线杆和输出方向。

### English

- Replaced the custom recipe browser with the game's native recipe picker,
  including search, category browsing, and recent picks.
- Recipe selection is limited to unlocked recipes suitable for production lines.
- Updated the configuration flow so belts, inserters, power poles, and output
  direction can be configured before choosing a recipe.

## 1.0.1

### 简体中文

- 修复自动计算的机器数量不超过产物半带目标时，快速生成蓝图会错误插入额外布局的问题。

### English

- Fixed an issue where Quick Blueprint inserted an extra layout when the
  automatically calculated machine count did not exceed the output half-belt
  target.
